# Third-party notices

CyberGraphics currently contains no third-party source code or binaries.

The project rule is that runtime code depends only on the C++ standard library
and operating system or driver headers. Build, CI, and documentation tooling is
allowed when it is not shipped as part of the runtime. Any exception must be
recorded here with its version, license, and purpose, and reviewed before a
release.

## Planned tooling (not shipped)

- CMake — build configuration.
- Ninja — build execution.
- GitHub Actions — continuous integration.
- Python 3 — repository checks and tools.

## Driver and OS SDKs (not redistributed)

- Windows SDK: Win32, DXGI, D3D12, D3DCompiler headers and system libraries.
- Later: Vulkan headers and loader, Metal frameworks.

System components such as `d3dcompiler_47.dll` are provided by Windows and are
not redistributed by CyberGraphics. This file will be regenerated by a script
before Phase 43.
