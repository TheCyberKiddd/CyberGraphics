# Reading notes

One note per roadmap phase: `phase-NN.md`. These are the raw notes taken while
reading the phase's "Read first" sources, not polished design documents.

## Template

```markdown
# Phase NN reading notes

Date: YYYY-MM-DD

## Sources

- Title, author, URL, accessed date.

## What I learned

Five to ten lines. Facts, constraints, and surprises.

## What applies to CyberGraphics

## What does not apply, and why

## Open questions

## Links to update

If a link has moved, record the replacement here and update the build guide.
```

## Rules

- Record the source, not just the idea. "I read somewhere" is not a source.
- Separate the specification from a tutorial. If they disagree, the
  specification wins and the difference is noted.
- Note what was deliberately rejected; it prevents re-litigating the same
  question in three phases.
