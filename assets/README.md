# Assets

- `source/` contains small, versioned source assets used by samples and tests.
- `cooked/` is generated by the cooker and is ignored by git.

Rules:

- Keep test assets small; large binaries belong in Git LFS or an external
  artifact store, decided by an ADR.
- Every source asset names its license or origin.
- Cooked output is reproducible from source plus the cooker version.
- Do not commit generated files.
